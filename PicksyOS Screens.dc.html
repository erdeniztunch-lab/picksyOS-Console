PicksyOS Operations Console design system.

Delivery One's public web palette and type, adapted for a dense operations tool. Tokens below are CSS custom properties; the same names export as a TypeScript object. Ratios are WCAG 2.x, measured against the theme's surface.

Rules the tokens enforce

Lime is identity and focusPrimary button, selected row, focus ring, the full stop. Never "healthy".
Priority is weight, not hueP1 solid, P2 outlined, P3 hairline, always with its label. Status hues stay free for state.
Every state has a shapeEach status chip pairs hue with an icon and a word, so nothing depends on colour alone.
Stale is neutral and dashedUnknown data gets grey, a dashed outline, a clock and "as of hh:mm". It never borrows the healthy style.

Deviations from the brand values

  1. Focus ring. Lime at 45 % alpha is about 1.4:1 on white, below the 3:1 a focus indicator needs. Light uses a solid green-deep ring with the lime halo around it; dark uses solid lime-bright.
  2. Status hues darkened / lightened. All four kept their hue. Light ok tint moved from #eef6df to #e8f2de so "healthy" is not the same fill as lime-soft, which now means "selected".
  3. Priority has no hue. P1 in red would read as Offline or Breached. Bands use fill weight plus the "P1" text instead.
  4. Muted text is #5f645f, not grey-500. Grey-500 drops to about 4.5:1 on the canvas and sunken greys; #5f645f holds 5.6:1 or more on every light background.
  5. Label tracking +0.1em, not +0.14em. Tighter for narrow panel headers; uppercase kept.
  6. Compact type scale 12–24 px, weight 400 body. As instructed; 44 px is used only on this page title.
  7. Confirm button is ink, not lime. One lime button per panel (the recommended action). Confirm sits under it, so it takes the neutral high-contrast fill to avoid two competing primaries.
